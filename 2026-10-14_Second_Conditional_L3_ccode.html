The Second Conditional

Imaginary situations: if + past, would + verb

Level 3 — Grammar Practice

 

The Form

If + past simple,   would + base verb
If Tara owned a boat, she would sail every weekend.
Tara would sail every weekend if she owned a boat.

The if-clause can come first or second. Use a comma only when it comes first.

Watch out: No would in the if-clause. If Tara would own a boat → If Tara owned a boat.
 

The Meaning

The past form does NOT mean past time. It means imaginary (not true now) or very unlikely.

If I could fly, I would land on the moon. (The truth: I can't fly.)
If a famous singer called me, I would scream. (This will probably never happen.)
 

First or Second Conditional?

First conditionalSecond conditional
Meaningreal, possibleimaginary, unlikely
Formif + present, will + verbif + past, would + verb
ExampleIf it snows tomorrow, we will build a snowman.If it snowed in July, we would build a snowman.

Ask yourself: Is this really possible? Yes → first. No, I'm imagining → second.

 

Were for Every Person

In the if-clause, use were with I, he, she, it, we, you, they.
If my cat were a person, she would be a queen.
Advice: If I were you, I would call a plumber.
 

Could, Might, and Negatives

could = would be able to  ·  might = maybe would
Negatives: didn't / weren't in the if-clause, wouldn't in the result
If Ray lived closer, he could walk to class.
If the music weren't so loud, we might hear each other.

Exercise 3 — Make It Imaginary

Read the true sentence. Write a second conditional sentence about it. Then click to check.

1. I don't have a passport, so I can't travel abroad.

If I had a passport, I could travel abroad. (or I would travel abroad) — Not true now → if + past, could/would + verb.

2. Mia doesn't know how to cook, so she eats out a lot.

If Mia knew how to cook, she wouldn't eat out so much. (or she would eat at home more) — knew in the if-clause, wouldn't in the result.

3. The hotel doesn't have a pool, so we don't stay there.

If the hotel had a pool, we would stay there. (or we might stay there) — had in the if-clause, would in the result.

4. Jae doesn't like spicy food, so he never orders curry.

If Jae liked spicy food, he would order curry. (or he might order curry) — liked in the if-clause, would + verb in the result.

5. Rita is shy, so she doesn't talk in meetings.

If Rita weren't so shy, she would talk in meetings. (or If Rita were not so shy …) — weren't for every person.

6. Ella doesn't have a library card, so she can't borrow books.

If Ella had a library card, she could borrow books. (or she would borrow books) — had in the if-clause, could in the result.
